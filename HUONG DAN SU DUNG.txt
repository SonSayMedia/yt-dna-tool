========================================================
        YT DNA TOOL  —  HƯỚNG DẪN VẬN HÀNH
========================================================

Phần mềm chạy trên máy anh (localhost). Gồm 4 chức năng:
  ① Phân tích kênh   → rút "khuôn tiêu đề" của kênh đối thủ (Title DNA)
  ② Quét từ khóa     → tìm video nhiều view + tái tạo tiêu đề theo khuôn
  ③ Phân tích ảnh    → rút "DNA phong cách" ảnh (thumbnail + ảnh nội dung)
  ④ SRT → prompt     → từ file phụ đề, sinh prompt thumbnail + prompt ảnh


--------------------------------------------------------
A. CHẠY PHẦN MỀM (1 cú nhấp)
--------------------------------------------------------
1. Nhấp đúp vào  run.bat  (hoặc shortcut "YT DNA Tool" ngoài Desktop).
2. Lần đầu sẽ cài đặt tự động 1–2 phút (các lần sau chạy ngay).
3. Trình duyệt TỰ MỞ trang:  http://127.0.0.1:5000
4. Muốn TẮT phần mềm: đóng cửa sổ đen (Command Prompt) đang chạy.

Lưu ý: cửa sổ đen phải để nguyên trong lúc dùng. Đóng nó = tắt phần mềm.


--------------------------------------------------------
B. NHẬP KEY (chỉ làm 1 lần)
--------------------------------------------------------
Trên trang web, ở mục "⚙️ Cài đặt":
  1. Dán KEY 9router vào ô "Key 9router".
  2. Dán KEY YouTube (YouTube Data API v3) vào ô "YouTube API key".
  3. Chọn mức suy luận của model nếu muốn (mặc định: Medium).
  4. Bấm "Lưu cài đặt".
Khi thấy "9router ✅ · YouTube ✅" là xong, dùng được mọi chức năng.

(Key chỉ lưu trong máy anh, ở file config.json — không gửi đi đâu.)


--------------------------------------------------------
C. QUY TRÌNH DÙNG (gợi ý theo thứ tự)
--------------------------------------------------------

① PHÂN TÍCH KÊNH (làm trước để có "khuôn tiêu đề")
   - Dán link kênh đối thủ (kênh muốn học theo).
   - Đặt tên khuôn (vd: "Kenh tam ly A").
   - Bấm "Phân tích 20 video top view" → phần mềm lưu lại khuôn.

② QUÉT TỪ KHÓA → TÁI TẠO TIÊU ĐỀ
   - Nhập từ khóa (gõ ngôn ngữ nào, quét thị trường đó).
   - Chọn chế độ:
        • "Thường"  → chọn mốc thời gian (3 tháng … 3 năm).
        • "Trend 48h" → chỉ video mới đăng trong 48 giờ qua.
   - Nhập số video, chọn ngôn ngữ tiêu đề tái tạo, chọn "Khuôn kênh" (ở bước ①).
   - Bấm "Quét & tái tạo".
   - Kết quả: bảng xếp theo view, bóc tách 3 thành phần, và tiêu đề tái tạo.

③ PHÂN TÍCH ẢNH → DNA PHONG CÁCH   (2 cách)
   - Cách 1: đặt tên hồ sơ DNA + tải lên vài ảnh thumbnail và ảnh nội dung.
   - Cách 2: đặt tên hồ sơ DNA + dán LINK VIDEO → phần mềm tự tải bản nhẹ,
             cắt khung hình, lấy thumbnail rồi phân tích.
   - Bấm nút tương ứng → phần mềm lưu "DNA phong cách" để dùng ở bước ④.

④ SRT → BỘ PROMPT
   - Chọn file .srt (TÊN FILE = tiêu đề video).
   - Chọn "DNA phong cách" (ở bước ③) và kiểu prompt (Veo có chuyển động / ảnh tĩnh).
   - Bấm "Sinh bộ prompt".
   - Nhận: 1 prompt thumbnail (hiện trên màn hình) + bảng prompt từng cảnh.
   - Bấm "⬇ Tải bộ prompt ảnh (.txt)" để lưu file prompt (đánh số) mang đi tạo ảnh
     trên Google Flow. Prompt viết bằng TIẾNG ANH.


--------------------------------------------------------
D. XỬ LÝ SỰ CỐ THƯỜNG GẶP
--------------------------------------------------------
• "Chức năng báo lỗi thiếu key": vào ⚙️ Cài đặt dán lại key, bấm Lưu.
• Trình duyệt không tự mở: gõ tay vào trình duyệt  http://127.0.0.1:5000
• Chạy lại mà báo lỗi cổng bận: phần mềm đang chạy sẵn — nó chỉ mở lại trình duyệt.
  Muốn khởi động lại thì đóng cửa sổ đen cũ rồi nhấp run.bat lại.
• Quét không ra kết quả: đổi từ khóa / nới mốc thời gian / kiểm tra key YouTube.
• Muốn tiêu đề "chất" hơn: ⚙️ Cài đặt → đổi model sang "High" → Lưu.

  Với 2–3 từ khóa/ngày là rất thoải mái.
