📊 Kết nối Google Sheet — tự điền tiêu đề + prompt thumb vào bảng của anh

Dán link "cổng" Apps Script (xem hướng dẫn bên dưới). Khi bấm "Làm thumb cả loạt", tool điền vào sheet: STT · tiêu đề tiếng Anh · tiếng Việt · link video · prompt thumb.

📖 Cách tạo "cổng" (làm 1 lần ~2 phút)
  1. Mở Google Sheet → menu Tiện ích mở rộng (Extensions) → Apps Script.
  2. Xoá code mẫu, dán đoạn code ở khung bên dưới (bấm "Copy code") → bấm 💾 lưu.
  3. Triển khai (Deploy) → Bản triển khai mới → loại Ứng dụng web (Web app).
  4. "Ai có quyền truy cập" = Bất kỳ ai (Anyone) → Triển khai → Cho phép (Authorize).
  5. Copy URL …/exec → dán vào ô trên → Lưu link → Gửi thử 1 dòng để kiểm tra.
